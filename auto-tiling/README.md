# Auto Tiling: свой авто-тайлинг в стиле i3

Своё расширение для GNOME Shell: каждое новое окно само делит экран, окнами
управляешь с клавиатуры, между окнами отступы, вокруг окна в фокусе цветная рамка.
Заменяет штатный Ubuntu Tiling Assistant.

Сделано 8 октября 2026 на Ubuntu 24.04, GNOME Shell 46, Wayland. На ноутбуке
стоят dash-to-panel (панель сверху) и Blur My Shell.

## Как раскладываются окна

Раскладка — BSP-дерево (dwindle, как в i3/Hyprland). Новое окно делит пополам
окно, которое было в фокусе, по его длинной стороне:

```
1 окно:        2 окна:        3 окна:        4 окна (фокус был на C):
┌─────────┐    ┌────┬────┐    ┌────┬────┐    ┌────┬────┐
│         │    │    │    │    │    │ B  │    │    │ B  │
│    A    │    │ A  │ B  │    │ A  ├────┤    │ A  ├──┬─┤
│         │    │    │    │    │    │ C  │    │    │C │D│
└─────────┘    └────┴────┘    └────┴────┘    └────┴──┴─┘
```

- У каждого рабочего стола (и монитора) своя раскладка.
- Закрыл окно — его место занимает соседнее.
- Свернул окно — остальные занимают место, развернул — оно возвращается на своё место.
- Развернул на весь экран (Alt+W) или F11 — окно перекрывает остальные, раскладка
  не меняется. Вернул обратно — окно встаёт в свой слот.
- **Не тайлятся (плавают):**
  - диалоги и окна с родителем;
  - окна, которые нельзя ресайзить;
  - всплывающие и служебные окна;
  - приложения из списка `floating-apps`;
  - окна, которые ты сам сделал плавающими (Super+F).
- **Мышь:**
  - перетащил тайловое окно на другое — они меняются местами;
  - отпустил в другом месте — окно вернётся в свой слот;
  - ресайз мышью тоже откатывается, размеры меняются клавишами.
- Блокировка экрана раскладку не сбрасывает.

## Клавиши

| Клавиши | Действие |
|---|---|
| Super+←→↑↓ | фокус на соседнее окно |
| Super+Shift+←→↑↓ | поменять окно местами с соседом |
| Super+Ctrl+←→↑↓ | сдвинуть границу окна (ресайз) |
| Super+R | сменить направление деления (рядом ↔ друг под другом) |
| Super+F | сделать окно плавающим / вернуть в тайлинг |
| Super+= | выровнять все размеры на этом столе |
| Super+T | выключить / включить тайлинг на этом рабочем столе |

Как работает ресайз: Super+Ctrl+→ двигает правую границу окна вправо, и окно
становится шире. Если справа у окна соседа нет, двигается левая граница, тоже
вправо, и окно становится уже. Остальные стрелки работают так же.

Пока расширение включено, у GNOME забираются клавиши, которые совпадают с нашими.
Сейчас это «переместить окно на другой монитор» (Super+Shift+стрелки) и
«прилипание к краю» (Super+←/→). Ещё выключается прилипание окна к краю экрана
при перетаскивании мышью (`edge-tiling`). Оригиналы сохраняются в настройке
`overridden-settings` и возвращаются, когда расширение выключают.

Super+H (свернуть) и Super+L (заблокировать экран) не трогаются, поэтому vim-клавиш
hjkl по умолчанию нет.

## Настройки

Окна настроек пока нет, всё меняется командами:

```bash
S="--schemadir $HOME/.local/share/gnome-shell/extensions/auto-tiling@nurik.local/schemas"
K=org.gnome.shell.extensions.auto-tiling

gsettings $S set $K gap-inner 8          # отступ между окнами, px
gsettings $S set $K gap-outer 8          # отступ от краёв экрана, px
gsettings $S set $K border-enabled true  # рамка вокруг окна в фокусе
gsettings $S set $K border-width 3       # толщина рамки, px
gsettings $S set $K border-color '#7764d8'   # цвет рамки, любой CSS-цвет
gsettings $S set $K border-radius 12     # скругление углов окна, px
gsettings $S set $K floating-apps "['org.gnome.Calculator', 'org.telegram.desktop']"   # всегда плавают

gsettings $S list-recursively $K         # посмотреть всё
gsettings $S reset $K gap-inner          # вернуть по умолчанию
```

Отступы, рамка и список плавающих приложений применяются сразу.

Клавиши задаются ключами с теми же именами, что и действия:
- `focus-left`, `focus-right`, `focus-up`, `focus-down`;
- `swap-*` и `resize-*` с теми же направлениями;
- `toggle-split`, `toggle-floating`, `equalize`, `toggle-tiling`.

Например:

```bash
gsettings $S set $K toggle-floating "['<Super><Shift>f']"
```

После смены клавиш выключи и включи расширение: только тогда заново освобождаются
совпадающие клавиши GNOME.

```bash
gnome-extensions disable auto-tiling@nurik.local && gnome-extensions enable auto-tiling@nurik.local
```

Как узнать id приложения для `floating-apps`: для большинства приложений это имя
их `.desktop`-файла без `.desktop`, например `org.gnome.Calculator` или
`org.telegram.desktop`. Если не сработало, открой Looking Glass (Alt+F2, `lg`)
→ вкладка Windows: там видны `wmclass` и `app`.

## Установка (новый ноутбук или после сброса)

Нужны Ubuntu 24.04 с GNOME 46 на Wayland (`gnome-shell --version`).

```bash
cd ~/Projects/ExtensionsUbuntu/auto-tiling
./install.sh
```

Скрипт:
1. копирует расширение в `~/.local/share/gnome-shell/extensions/`;
2. компилирует схему настроек;
3. выключает Tiling Assistant;
4. включает Auto Tiling.

Потом **выйди из системы и зайди снова**: под Wayland GNOME загружает новый код
расширения только при входе.

Проверить после входа:

```bash
gnome-extensions info auto-tiling@nurik.local   # State: ACTIVE
```

Затем открой два-три окна: они должны встать рядом, с отступами и рамкой.

## Выключить или откатиться на Tiling Assistant

```bash
gnome-extensions disable auto-tiling@nurik.local
gnome-extensions enable tiling-assistant@ubuntu.com
```

Забранные клавиши GNOME вернутся сами. Удалить совсем:
`rm -rf ~/.local/share/gnome-shell/extensions/auto-tiling@nurik.local`.

## Как устроено

```
auto-tiling/
├── README.md
├── install.sh
├── tests/tree.test.js           юнит-тесты дерева и клавиш (node --test tests/*.test.js)
└── auto-tiling@nurik.local/
    ├── metadata.json            GNOME 46, работает и на экране блокировки
    ├── extension.js             включение/выключение, связывает модули
    ├── tree.js                  BSP-дерево: вставка, удаление, раскладка с отступами, соседи, swap, ресайз
    ├── accel.js                 сравнение сочетаний клавиш
    ├── tiler.js                 следит за окнами и ставит их в слоты
    ├── keybindings.js           клавиши и временный перехват клавиш GNOME
    ├── border.js                рамка вокруг окна в фокусе
    └── schemas/                 схема настроек (+ скомпилированная)
```

- **tree.js** и **accel.js** не зависят от GNOME. Их проверяют тесты в node:
  `node --test tests/*.test.js`.
- **tiler.js:**
  - новое окно берётся в работу после первого кадра (сигнал `first-frame`),
    раньше клиент ещё может поменять тип и размер окна;
  - на каждый рабочий стол и монитор своё дерево;
  - окна ставятся через `move_resize_frame`;
  - рабочая область берётся из `get_work_area_for_monitor`, поэтому верхняя
    панель учитывается.
- **keybindings.js:**
  - перед включением ищет наши сочетания в `org.gnome.desktop.wm.keybindings`,
    `org.gnome.mutter.keybindings`, `org.gnome.mutter.wayland.keybindings` и
    `org.gnome.shell.keybindings`;
  - найденные убирает, оригиналы сохраняет в `overridden-settings`;
  - при выключении возвращает. Если шелл упадёт, оригиналы останутся в dconf и
    вернутся при следующем выключении.
- **border.js:** рамка — это виджет среди окон, стоит сразу над окном в фокусе.
  Поэтому окна, которые лежат поверх, её закрывают, а в обзоре она прячется вместе с окнами.

## Проверка без выхода из системы

GNOME можно запустить в отдельном окне с копией настроек. Тест не трогает
настоящую сессию.

```bash
cd ~/Projects/ExtensionsUbuntu/auto-tiling
T=/tmp/at-test; mkdir -p $T/dconf && cp ~/.config/dconf/user $T/dconf/user
XDG_CONFIG_HOME=$T dbus-run-session -- bash -c '
  gnome-shell --nested --wayland &
  sleep 12
  for n in A B C; do
    WAYLAND_DISPLAY=wayland-1 GDK_BACKEND=wayland DISPLAY= python3 tests/win.py $n &
    sleep 2
  done
  sleep 60; kill %1'
```

Пояснения:
- `tests/win.py` открывает простое тестовое окно на GTK3. `python3 tests/win.py X fixed`
  открывает окно, которое нельзя ресайзить: оно должно остаться плавающим.
- Приложения на GTK4 (`gnome-text-editor` и т.п.) во вложенной сессии могут не
  показать окно, поэтому для теста лучше `tests/win.py`.
- Если расширение выключали командой `gnome-extensions disable`, оно попадает в
  список `disabled-extensions` и во вложенной сессии не запустится. Убери его
  оттуда в копии настроек.
- Ошибки расширения видны в выводе как `JS ERROR`.
